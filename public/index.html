固定链接隧道（Tailscale Funnel / Cloudflare Named Tunnel）
Tailscale Funnel（0 元免域名 · 永久 *.ts.net） 检测中

免费个人版即可获得永久固定 HTTPS 域名（手机免装 App 直连），通过本机鉴权网关保护访问。

未检测到 tailscale，请先安装并登录账号：
brew install --cask tailscale
  1. 安装并登录 Tailscale，在后台 DNS 设置开启 MagicDNS 与 HTTPS Certificates，并在 ACL 启用 Funnel。
  2. 点击上方「一键开启 Tailscale Funnel」（或终端执行 tailscale funnel --bg 43310），会自动识别并生成扫码配对链接。
Cloudflare Named Tunnel（0 元隧道 · 自备域名）

隧道本身完全免费且不限时长；适合已有 Cloudflare 托管域名的用户作为系统服务 24 小时常驻。

  1. 登录 Cloudflare Zero Trust → Networks → Tunnels 创建隧道，Public Hostname 指向 http://127.0.0.1:43310。
  2. 本机终端运行 cloudflared service install <你的Token>，再在下方填入你的固定域名生成配对码。

此固定域名同样受本地鉴权网关保护：首次扫码后可收藏到手机桌面，重置二维码会立即踢掉旧手机。
